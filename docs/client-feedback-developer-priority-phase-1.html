Acceptance checklist

  • Desktop and mobile nav show exactly four approved labels.
  • Labels persist after reload/cache clear/login state changes.
  • Existing active-route / aria-current behavior remains intact.
  • No visible breadcrumb on editorial or WooCommerce routes.
  • WooCommerce classic breadcrumb does not reappear.
  • Consultation CTA text is readable by default, hover and keyboard focus.
  • Shared CTA callers do not regress.
  • No new parallel owner/controller is introduced.
  • Focused regression contracts are updated/added.
  • Canonical runtime/test harness passes with a clean tree.
