# Graphik runtime source provenance

The production Graphik runtime files are copied byte-for-byte from the WOFF files uploaded under `docs/fonts/`. Those uploaded files match the previously selected source in `opr/bloc` at commit `ddd732dd29409153802e37936a365794368c30bf`; no OTF/TTF/WOFF2 conversion is performed by this repository.

Runtime/source Git blob identities:

- `Graphik-Light.woff` — `68b3f3d5ca29f404ab37f940c132d5dda5ec9366`
- `Graphik-Regular.woff` — `86d786a001def16f845d86576f958e2736346929`
- `Graphik-Medium.woff` — `ea2b892abfdd0a1111c70e6d993892ccc2d09e0d`
- `Graphik-Semibold.woff` — `a50f4755db0728e299e3e5eae19c2213774e8ca8`
- `Graphik-Bold.woff` — `5ff3d9424501ea46949c524879cdfc49b8c22b34`

`Felixti.woff2` remains the existing owner-supplied Felix Titling runtime asset and is not changed by this font replacement.
