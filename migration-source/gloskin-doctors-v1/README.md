# Gloskin Doctors v1

Deterministic source package for the 13-doctor official roster documented in `docs/task-shop-filters-contact-operations-doctor-migration.md` (research date 2026-08-17).

Authoritative page: `https://gloskin.id/founder-and-dokter-gloskin/`.

This bundle intentionally contains identity + provenance only. SIP number, individual schedule, branch assignment, specialization/profile wording, booking target and featured media are omitted because the implementation source package does not provide sufficiently unambiguous per-doctor facts for those fields. No stock portrait is used.

Runtime import owns only post title/slug and migration provenance meta. Existing editor-managed medical/profile fields are not cleared or synthesized.
